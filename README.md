# termux-android-apk-builder
Build native Android APKs entirely on-device with Termx, no PC or Android Studio required. GUI tooling for compiling, packaging, signing and installing Nim, Raylib and other native Android projects.

# Termux-AppForge


Local Data
- The "local_data/" folder stores local settings, API configurations, shortcuts, and other device-specific data.
- It is created automatically when needed and is excluded from GitHub using ".gitignore".
